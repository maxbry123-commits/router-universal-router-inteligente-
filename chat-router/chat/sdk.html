# ==== Qwen/Qwen2.5-Coder-0.5B-Instruct-GGUF · SDK/API (OpenAI-compatible) ====
# El router acepta 'model: qwen2.5-coder-0.5b' y enruta a ESTA LLM local (Grupo 2).
# Autenticacion: cabecera x-api-key = la clave del router.
#
# --- 1) Python (SDK openai) -------------------------------
from openai import OpenAI
import os

client = OpenAI(
    base_url="https://comand-center-1-space-grupo-1-router-mvp-1.hf.space/v1",
    api_key=os.environ["UNIVERSAL_KEY"],
    default_headers={"x-api-key": os.environ["UNIVERSAL_KEY"]},
)
r = client.chat.completions.create(
    model="qwen2.5-coder-0.5b",
    max_tokens=200,
    messages=[{"role": "user", "content": "Escribe una funcion Python"}],
)
print(r.choices[0].message.content)

# --- 2) Sin router: contra el Space directamente -----------
import requests, os
r = requests.post(
    "https://comand-center-1-space-grupo-2-router-llm-hf-1.hf.space/v1/chat/completions",
    headers={"x-api-key": os.environ["UNIVERSAL_KEY"]},
    json={"messages": [{"role": "user", "content": "di ok"}], "max_tokens": 64},
    timeout=120)
print(r.json()["choices"][0]["message"]["content"])

# --- 3) cURL (pegar en cualquier sistema) ------------------
curl -sS -X POST "https://comand-center-1-space-grupo-1-router-mvp-1.hf.space/v1/chat/completions" \
  -H 'Content-Type: application/json' \
  -H 'x-api-key: $UNIVERSAL_KEY' \
  -d '{"model":"qwen2.5-coder-0.5b","messages":[{"role":"user","content":"di ok"}],"max_tokens":64}'
Como funciona el dataset de este modelo y que hay instalado en HF
Los 3 pesos viven en el dataset COMAND-CENTER-1/swe-code-hf-gguf (GGUF, prefijo owner__repo__fichero). El Space los descarga, verifica el sha256 contra llm system HF/registry.json y los sirve con llama-server (b12000) en CPU. Encima hay datasets por modo (swe-code-modes) y LoRAs (swe-code-loras): el dataset es el formato de la tarea (instruccion/respuesta/LoRA) y el LoRA el delta de pesos que el Space puede aplicar en caliente; el router elige dataset+LoRA segun el modo detectado.
