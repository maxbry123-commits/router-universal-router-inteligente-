# OpenBot: Run a team of AI agents on your computer

Available on macOS, Windows, Linux, iOS, Android.

## Meet OpenBot

Persistent AI teammates on your own computer. Run Codex, Claude, Gemini and Grok with the plans you already pay for, or your own model.

[Download for Linux](https://openbot.run/download/linux/latest) | [Contact](https://openbot.run/contact)

### Agents work as a team
Each agent has its own name, instructions and workspace. Agents send each other messages, hand off tasks and share files. (Preview: Ada, Linus, Grace in #launch hand off a Safari sign-in test fix, review and merge.) Providers shown: Codex, Claude Code, Gemini, Grok, OpenCode, Cursor, Cline.

### Use the AI plan you have
Run [Codex](https://openbot.run/providers/codex), [Claude Code](https://openbot.run/providers/claude-code), [Gemini](https://openbot.run/providers/gemini), [Grok](https://openbot.run/providers/grok), [OpenCode](https://openbot.run/providers/opencode), [Cursor](https://openbot.run/providers/cursor), [Cline](https://openbot.run/providers/cline), [Muse Code](https://openbot.run/providers/muse-code), [Pi](https://openbot.run/providers/pi) or [Mercury](https://openbot.run/providers/inception). Or add [an ACP agent](https://openbot.run/providers/custom-agents), an OpenAI-compatible endpoint, [Ollama or LM Studio](https://openbot.run/providers/local-models).

### Stored on your computer
Workspaces, conversations, files and browser data stay on the computer that runs OpenBot, not on our servers.

### Change the provider, keep the agent
An agent keeps its workspace and conversation when you restart the app or move it to a different provider. When a plan reaches its limit, it can move to a backup model.

### A built-in browser
Agents open, read and control pages in a browser that is built into OpenBot.

### Queue the next task
Send more work while an agent is busy. Messages wait in a queue that you can pause, resume or cancel.

## FAQ

**Is OpenBot free?** Yes. OpenBot costs $0, with no locked features. You pay only your AI provider, through the plan or API key you already have.

**Is OpenBot open source?** The source code is public on GitHub, under the PolyForm Noncommercial License 1.0.0. You can read, change and run it for any noncommercial purpose. It is not an open-source license as the OSI defines one: commercial use needs a separate license.

**Can I use my ChatGPT or Claude plan?** Yes. Codex signs in with your ChatGPT plan, and Claude Code with your Claude plan. Gemini uses a Google AI Pro or Ultra plan. OpenCode has free models that need no account.

**Which AI models can OpenBot use?** Codex, Claude Code, Gemini, Grok, OpenCode, Cursor, Cline, Muse Code and Pi, and Inception's Mercury models. You can also run any agent that speaks the Agent Client Protocol, such as Goose or Qwen Code, connect any OpenAI-compatible endpoint, and use local models in Ollama or LM Studio.

**What happens when my plan reaches its limit?** An agent can move to a backup model on another provider when its plan reaches its limit, or when its provider is overloaded or down. It keeps its chat and workspace, and a note in the chat shows the switch.

**How do I start?** Download OpenBot and connect a provider. Then describe the agent you want in one prompt, check its instructions and save it. You can send it work at once: messages wait in a queue until it is free.

**Where does my data go?** Workspaces, conversations, attachments and browser data stay on the computer that runs OpenBot. The AI provider you choose receives the prompts that your agents send to it, and the pages that agents open use the network.

**Which computers can run OpenBot?** macOS 13 or newer on Apple silicon or Intel, Windows 10 or newer on x64, and Linux on x64 or arm64 as an AppImage.

**Is it safe to let agents work on my computer?** OpenBot is a development preview. Agents can read and change files, run commands, use the network and control the built-in browser without asking each time. Give them only tasks you trust, and keep backups.
