## FICHA: UNA SOLA, MÍNIMA
ficha_general.json, máximo 60 líneas, una sección por modelo del plan Qwen. Cada sección SOLO lleva:
- modelo y variante recomendada
- parámetros recomendados por Qwen (temperatura, top_p, top_k, repetición, tokens de salida, ventana)
- modo de razonamiento recomendado
- formato de salida y manejo de herramientas
- límites (timeout, reintentos, tokens por vuelta)
- herramientas permitidas
- referencia al prompt: ruta a system-prompt/nucleo/manifest.json + sha256 (apunta, no copia)
PROHIBIDO: texto de prompt, reglas, motor, modos, carril rápido, código, campos "por si acaso".

## SYSTEM PROMPT: SE ORGANIZA, NO SE TOCA
- El texto de cada archivo de prompt NO se edita. Solo se mueve y se indexa en manifest.json con su sha256 original.
- Se organiza en: núcleo, reglas por tema, bloques, ciclo, pasos.
- El ciclo wordflow_loop se queda dentro del prompt. El workflow-loop-yaiwes NO se mueve aquí: es del Edificio 2.
- prompt_engine.py (máximo 100 líneas): verifica los sha256 del manifest; arma la lista de puntos a cumplir; llama al modelo mediante una función que le entrega el Router (llamar(plugin, accion, payload)); no importa nada del Router; verifica cada punto con reglas deterministas (el modelo no se califica a sí mismo); repite solo con lo pendiente.
  Topes: 8 vueltas, 120 s por llamada, 900 s total, parar tras 2 vueltas sin progreso.
  Estados finales: cumplido, sin_progreso, tope_vueltas, tope_tiempo, error.

## PLUGIN DE CONEXIÓN
servicio_llm/plugin/ficha.json + plugin.py (máximo 80 líneas), válido bajo validator_v2. Acciones: listar_fichas, chat_async, resultado. Antes de cada acción comprueba que la ficha tenga permiso para esa herramienta; si no, bloquea con error claro.

## CÓDIGO MÍNIMO
- Archivos nuevos: prompt_engine.py, plugin.py, test_servicio.py. Nada más.
- Máximo 100 líneas por archivo y 300 en total.
- Funciones de máximo 25 líneas. Solo librería estándar. Sin exec, eval ni shell. Ninguna clave en código ni logs.

## PRUEBAS (antes de subir)
- Los sha256 del prompt coinciden con el manifest.
- La ficha valida y no tiene campos prohibidos.
- El plugin valida bajo validator_v2.
- Una herramienta no permitida se bloquea.
- El ciclo termina en cada estado final con un modelo simulado.

## PROHIBIDO (para y repórtalo como violación de seguridad)
- Editar o reformatear cualquier prompt.
- Construir o tocar el enrutador, el bus, el registro de plugins o http_out.
- Modificar el validador, el esquema o el contrato v2.
- Tocar componentes/, el Router, el banco o los secretos.
- Borrar archivos o crear archivos fuera de la estructura.
- Inventar campos o dejar que otro agente decida por ti.

## ENTREGA
