## Hallazgos X-Ray

1. **Los artefactos no están extraídos**: la colección principal son ZIP fragmentados por tamaño.
2. **`python-sdk` y `MCP-Python-SDK` apuntan al mismo repositorio fuente** (`modelcontextprotocol/python-sdk`) pero a commits diferentes; por trazabilidad se preservan ambos y se marca el segundo como duplicado histórico.
3. **`plex` = IBM Plex tipografía**, no software de routing; su presencia es útil solo para UI/branding.
4. **`vLLM-Semantic-Router`, `vLLM-Router`, LiteLLM, SGLang, vLLM y llama.cpp** son los componentes más directamente relacionados con enrutamiento/serving de modelos.
5. **RouterArena** no enruta tráfico de producción: sirve para evaluar routers y comparar precisión, coste, robustez y latencia.
6. **Sentence-Transformers/Qdrant/Chroma** pueden producir señales semánticas y memoria para una política de routing.
7. **FastAPI/Starlette/Uvicorn/Gunicorn/HTTPX** forman la capa API/servidor/red; **Prometheus/Grafana/Phoenix** cubren observabilidad.
