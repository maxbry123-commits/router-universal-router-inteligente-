# T02 — Colmena: YaiwesHive + EngineeringLoop conectados a NUESTRO Router
ALCANCE: chat router/05-AGENTES/colmena
ARCHIVOS: router_cliente.py, agentes.py, colmena.py, __init__.py, tests/__init__.py, tests/test_colmena.py, README.md

## Objetivo
Implementar el ciclo de trabajo del equipo definido por el Director en los documentos 22 y 23 (archivo de lectura incluido)
y el registro AGENTES.yaml (incluido). Todos los agentes piensan llamando a NUESTRO Router (nunca Anthropic).

## Archivos (dentro del ALCANCE)
1. `router_cliente.py` — `RouterCliente.chat(prompt, rol) -> str`: POST `<LIVE_URL>/chat/send` con {"message", "max_tokens"};
   cabeceras `Authorization: Bearer $HF_TOKEN` y `X-API-Key: $RIU_ROUTER_API_KEY`; LIVE_URL = línea `LIVE_URL=` del archivo
   https://raw.githubusercontent.com/maxbry123-commits/router-universal-router-inteligente-/main/router%20inteligente%20universal/agents-yaiwes/ROUTER_JOB_PAUSE.flag
   (urllib, sin dependencias). 3 reintentos. Si `SIMULADO=1`: devuelve JSON fijo por rol (para tests), sin red.
2. `agentes.py` — adaptadores con la MISMA interfaz: `RowboatDirector.submit(goal)`; `Hermes` y `OpenClaw` con plan/critique/review/reconsider
   (+ `Hermes.synthesize`, `OpenClaw.review_plan`); `ClaudeArquitecto.design`; `GrokEjecutor.execute/correct`; `ClaudeRevisor.review`;
   `MetaEquipo.review_parallel` (4 en paralelo con asyncio.gather: código, tests, visual, adversarial); `MetaFixer.correct`.
   Cada uno arma un prompt corto con su rol, pide JSON al Router y lo parsea (si no es JSON válido → {"approve": false, "issues": ["json"]}).
3. `colmena.py` — `YaiwesHive.run(goal)` (doc 23: plan dual → debate → Sheriff → reparto → Sentinel → revisión dual → Judge) y
   `EngineeringLoop.run(request)` (doc 22: diseño → ejecución → revisión hasta 3 veces → Meta ×4 → agregador → fixer → revalidación).
   Importa Sheriff/Judge/Sentinel desde `../gobierno` si existen; si no, usa stubs mínimos locales marcados `# TODO T01`.
4. `tests/test_colmena.py` — pytest con `SIMULADO=1`: una meta termina PASS; un caso REVISE; un caso BLOCK por Sheriff.
5. `README.md` — micro resumen + micro diagrama.
