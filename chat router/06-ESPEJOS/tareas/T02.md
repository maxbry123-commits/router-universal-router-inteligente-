# T02 — Colmena: YaiwesHive + EngineeringLoop conectados a NUESTRO Router
ALCANCE: chat router/05-AGENTES/colmena

## Objetivo
Implementar el ciclo de trabajo del equipo definido por el Director en los documentos 22 y 23
(`chat router/00-INSTRUCCIONES/INPUT-BLOCK-VERBATIM-PARTE-5-B-DOCS-22-23.md`) y el registro `chat router/05-AGENTES/AGENTES.yaml`.
Todos los agentes piensan llamando a NUESTRO Router (nunca Anthropic): POST <LIVE_URL>/chat/send con {message, provider, model, max_tokens},
cabeceras Authorization: Bearer <HF_TOKEN> y X-API-Key: <RIU_ROUTER_API_KEY> (leer de variables de entorno; LIVE_URL de
`router inteligente universal/agents-yaiwes/ROUTER_JOB_PAUSE.flag`, solo lectura).

## Archivos a entregar (todos dentro del ALCANCE)
1. `router_cliente.py` — cliente mínimo del Router (lee LIVE_URL, reintenta 3 veces, timeout; modo `SIMULADO=1` que devuelve respuestas fijas para tests).
2. `agentes.py` — adaptadores con la MISMA interfaz: `RowboatDirector.submit(goal)`, `Hermes.plan/critique/synthesize/review/reconsider`,
   `OpenClaw.plan/critique/review_plan/review/reconsider`, `ClaudeArquitecto.design`, `GrokEjecutor.execute/correct`, `ClaudeRevisor.review`,
   `MetaEquipo.review_parallel` (4 en paralelo con asyncio.gather: código, tests, visual, adversarial) y `MetaFixer.correct`.
   Cada uno arma un prompt corto con su rol y pide JSON al Router; valida el JSON contra los contratos.
3. `colmena.py` — `YaiwesHive.run(goal)` (doc 23: plan dual → debate → Sheriff → Ruflo reparte → Sentinel → revisión dual → Judge) y
   `EngineeringLoop.run(request)` (doc 22: diseño → ejecución → revisión hasta 3 veces → Meta ×4 → agregador → fixer → revalidación).
   Importa Sheriff/Judge/Sentinel/contratos desde `../gobierno` si existen; si aún no existen, usa stubs mínimos marcados `# TODO T01`.
4. `tests/test_colmena.py` — pytest con `SIMULADO=1`: una meta recorre toda la colmena y termina PASS; un caso REVISE; un caso BLOCK por Sheriff.
5. `README.md` — micro resumen + micro diagrama de flujo.

## Aceptación
- Tests pasan con `SIMULADO=1` (pega la salida real en el informe).
- Si hay HF_TOKEN y RIU_ROUTER_API_KEY en el entorno, 1 prueba real contra el Router (si no, anotarlo como GAP).
- Nada fuera del ALCANCE. Máximo 500 líneas por archivo. Informe en `chat router/06-ESPEJOS/informes/T02.md`.
