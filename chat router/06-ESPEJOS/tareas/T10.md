# T10 — OmniRoute: modelos gratuitos automáticos sin UI (auto/best-free) + listo para x10
ALCANCE: chat router/08-OMNIROUTE/autofree
ARCHIVOS: aplicar_parche_autofree.sh, parche_virtualFactory.py, prueba_autofree.py, tests/__init__.py, tests/test_parche.py, README.md

## Objetivo (orden del Director 2026-09-28)
Que OmniRoute use proveedores gratuitos SIN interfaz, SIN API key y SIN registrarlos a mano: el agente llama `model: "auto/best-free"`
(o `auto/coding:free` para código) y OmniRoute elige del catálogo los proveedores `noAuth=true` + `hasFree=true` + `serviceKinds` con "llm", con fallback.

## Hecho verificado por el Director (código real de OmniRoute)
`open-sse/services/autoCombo/virtualFactory.ts` limita el auto-routing sin credenciales a opencode:
`const AUTO_COMBO_NOAUTH_ALLOWLIST = new Set<string>(["opencode"]);`
Parche propuesto: añadir `hasFree?: boolean` al tipo `NoAuthProviderDefinition`, quitar la allowlist y en `isChatAutoComboNoAuthProvider`
reemplazar la condición de allowlist por `if (!bypassAllowlist && providerDef.hasFree !== true) return false;` (mantener el filtro "llm").
Advertencia: amplía el pool a proveedores menos fiables; el fallback/circuit breaker de OmniRoute los aparta tras fallos.
