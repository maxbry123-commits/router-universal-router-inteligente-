## Problema real (verificado 27-sep)
Claude Code + LiteLLM + NVIDIA Kimi K3: Claude Code leía 1 archivo y sus llamadas de herramientas se cortaban.
Causa (investigación del Director): Claude Code habla Anthropic `/v1/messages` (SSE, tool_use/tool_result, thinking, output_config,
subagentes con nombres claude-opus/sonnet/haiku); NVIDIA API Catalog habla OpenAI `/v1/chat/completions`. Hace falta traducción real.
Fallos conocidos: `reasoning` no soportado (400), `thinking: {type: adaptive}` no traducido, subagentes/plugins que piden `claude-opus-*`.

## Solución a construir (reutiliza código existente; no reinventes)
Base: Free Claude Code https://github.com/codeaashu/free-claude-code (implementa /v1/messages, /v1/messages/count_tokens, /v1/models y
normaliza thinking, tool calls, streaming y alias Opus/Sonnet/Haiku). Alternativa: Claude-NIM Proxy https://github.com/claude-server/claude-nim.
1. `normalizar.py` — funciones puras: quitar `reasoning`/`output_config`; `thinking adaptive` → formato del proveedor o eliminar;
   alias claude-opus/sonnet/haiku-* → modelo NVIDIA elegido; tools Anthropic ↔ OpenAI (tool_use ↔ tool_calls, tool_result ↔ role tool);
   respuesta OpenAI → bloques Anthropic (text, tool_use) con stop_reason correcto.
2. `pasarela.py` — FastAPI mínima en :8082 con /v1/messages (stream y no stream), /v1/messages/count_tokens (estimación), /v1/models.
   Upstream `https://integrate.api.nvidia.com/v1/chat/completions`, modelo por env `MODELO` (Kimi K3 por defecto), clave `NVIDIA_API_KEY`.
3. `iniciar_claude_code.sh` — arranca la pasarela y exporta ANTHROPIC_BASE_URL=http://127.0.0.1:8082, ANTHROPIC_AUTH_TOKEN,
   ANTHROPIC_DEFAULT_OPUS/SONNET/HAIKU_MODEL, CLAUDE_CODE_SUBAGENT_MODEL; ejecuta `claude --bare` si existe la opción (plugins causan 400).
4. `tests/test_normalizar.py` — pytest de la traducción de ida y vuelta (texto, tool_use con args, tool_result, thinking, alias).
5. `INVESTIGACION.md` — qué dicen las fuentes y qué elegiste. Incluye la vía oficial DeepSeek Harness → Claude Code como subagente:
   `dsh plugin add @deepseek-ai/dsh-subagent-claude-code` y `@deepseek-ai/dsh-hooks-claude-code` (https://github.com/deepseek-ai/deepseek-harness),
   y DeepSeek directo `https://api.deepseek.com/anthropic` (requiere DEEPSEEK_API_KEY, hoy NO disponible → GAP).
6. `README.md` — micro resumen + cómo lo usan los espejos.
