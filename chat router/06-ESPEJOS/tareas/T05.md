# T05 — Funciones del chat (backend): Action Registry, Council, rewind, compact, Archify, WORK
ALCANCE: chat router/10-CHAT-FUNCIONES
ARCHIVOS: action_registry.py, council.py, rewind.py, compact.py, archify_cmd.py, work.py, rutas.py, __init__.py, tests/__init__.py, tests/test_funciones.py, README.md

## Objetivo
Implementar como módulos Python independientes (stdlib + fastapi) las funciones que el Director pidió para el chat (instrucción M16, en
`chat router/00-INSTRUCCIONES/INPUT-BLOCK-VERBATIM-CHAT-Y-PANEL.md`). Opus los monta en el Router después; tú NO tocas el Router.
Los modelos se llaman por el Router con `chat router/05-AGENTES/colmena/router_cliente.py` si existe; si no, un cliente mínimo local
(POST <LIVE_URL>/chat/send, LIVE_URL de ROUTER_JOB_PAUSE.flag por HTTP raw) con modo `SIMULADO=1` para tests.

## Archivos
1. `action_registry.py` — registro botón→acción: watchdog.start/stop, workflow.run/pause/resume, task.schedule/cancel, pool.dispatch,
   document.attach, command.execute, memory.search, browser.open, council.ask, rewind, compact, archify. Cada acción = función con
   entrada/salida JSON validada; `ejecutar(action_id, payload)`; comandos de texto `/run /loop /schedule /watchdog /rewind /compact /council /archify`
   se traducen al action_id.
2. `council.py` — `ask_council(pregunta, modelos=3)`: pide la misma pregunta a N modelos en paralelo (asyncio), revisión cruzada y síntesis
   (patrón karpathy/llm-council). Devuelve respuestas + síntesis.
3. `rewind.py` — checkpoints por conversación/agente: `guardar(conv_id, estado)`, `volver(conv_id, pasos=1)` (doble Escape / /rewind).
4. `compact.py` — `compactar(historial) -> resumen` con: objetivo, decisiones, archivos, estado, siguiente paso (parche de recuperación).
5. `archify_cmd.py` — `/archify <texto|tarea>` → diagrama Mermaid (flujo de la tarea, trabajo hecho o auditoría) generado por el modelo y validado (debe empezar por `flowchart`/`graph`).
6. `work.py` — barra WORK: estados RUNNING/PAUSED/CANCELLED/DONE por trabajo; pausar, cancelar, reintentar, aprobar; tareas con progreso %.
7. `rutas.py` — `build_router()` FastAPI con POST /acciones/{action_id}, POST /council, POST /rewind, POST /compact, POST /archify, GET/POST /work.
8. `tests/test_funciones.py` — pytest con SIMULADO=1: cada acción y cada ruta (TestClient).
9. `README.md` — micro resumen + tabla botón → action_id → función.

## Aceptación
`SIMULADO=1 python -m pytest "chat router/10-CHAT-FUNCIONES" -q` pasa. Informe con salida real. Máx. 500 líneas por archivo.
