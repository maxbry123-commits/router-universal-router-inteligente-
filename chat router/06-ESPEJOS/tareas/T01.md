# T01 — Gobierno del equipo (Sheriff, Judge, Sentinel, contratos, MirrorManager)
ALCANCE: chat router/05-AGENTES/gobierno
ARCHIVOS: contratos.py, sheriff.py, judge.py, sentinel.py, mirror_manager.py, __init__.py, tests/__init__.py, tests/test_gobierno.py, README.md

## Objetivo
Implementar en Python (stdlib + pyyaml si hace falta) las piezas de CÓDIGO del gobierno de agentes, tal como las definió el Director
en los documentos 22 y 23 (archivo de lectura incluido en el chat). Copia su diseño; no inventes otro.

## Archivos (dentro del ALCANCE)
1. `contratos.py` — dataclasses `Job` {job_id, objective, scope, acceptance, state, attempt, evidence, issues} y `Result`
   {job_id, agent, status, changed_files, tests, issues, evidence, next_action} (doc 22) + `Task` {id, objective, role, dependencies,
   allowed_paths, acceptance, evidence} y enum `State` INPUT, PLANNING, DEBATE, SHERIFF, EXECUTION, REVIEW, JUDGMENT, PASS, REVISE, BLOCK (doc 23).
   Con `to_dict()/from_dict()` y validación de campos obligatorios (ValueError si faltan).
2. `sheriff.py` — `Sheriff.validate(plan) -> (bool, motivo)` con las reglas del doc 23 (acceptance obligatorio, dependencias válidas,
   sin rutas absolutas ni `..`) + prohibir rutas que empiecen por `.github/` o `router inteligente universal/`.
3. `judge.py` — `Judge.decide(task, evidence, hermes_review, openclaw_review) -> "PASS"|"REVISE"|"BLOCK"` (doc 23; BLOCK si evidence trae `unauthorized_change`).
4. `sentinel.py` — `Sentinel.inspect(task_state) -> {"action": RECOVER|REASSIGN|BLOCK|CONTINUE}` (doc 23) + mismo error 3 veces → REASSIGN;
   `heartbeat_at` más viejo que `max_minutos` (por defecto 30) → REASSIGN.
5. `mirror_manager.py` — `MirrorManager(repo_dir)` con `SYSTEM_MAP` (doc 22); `create(job_id, system)` usa `git worktree add ../mirrors/<job> -b mirror/<job>`
   (subprocess); `diff()`; `merge_selectivo(sheriff)` solo si Sheriff aprueba; `keep_for_debug()`. En tests usa un repo git temporal (tmp_path).
6. `tests/test_gobierno.py` — pytest, mínimo 3 casos por clase (PASS y fallos). Importa con `sys.path.insert(0, str(Path(__file__).parents[1]))`.
7. `README.md` — micro resumen + micro diagrama (Rowboat → Hermes+OpenClaw → Sheriff → Ruflo → Colmena → Sentinel → revisión → Judge).
